# Data Mining Course Project

Course project for the Data Mining class.

## Project objective

This project investigates the effect of data preprocessing methods on
the performance of machine-learning classification algorithms.

## Dataset

The dataset contains 920 records, 14 input features, one identifier
column, and a five-class target variable.

## Required models

- Support Vector Machine with Linear kernel
- Support Vector Machine with RBF kernel
- K-Nearest Neighbors
- Decision Tree

## Project structure

- `data/raw`: Original dataset
- `data/processed`: Processed datasets
- `notebooks`: Main Jupyter Notebook
- `outputs/figures`: Generated charts
- `outputs/tables`: Generated tables
- `report`: Final report
- `presentation`: Final presentation

## Python version

Python 3.10.11
